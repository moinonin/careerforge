### Task 1: Rate Limiting Middleware

**Objective:** Implement per-user rate limiting on all API endpoints using Redis sliding window.

**Files:**
- Create: `backend/middleware/rate_limit.py`
- Modify: `backend/main.py:81` — add rate limiter middleware
- Modify: `backend/config.py:77` — use existing rate limit config values
- Test: `tests/test_rate_limit.py`

**Step 1: Write failing test**
```python
# tests/test_rate_limit.py
import pytest
from httpx import AsyncClient
from backend.main import create_app

@pytest.mark.asyncio
async def test_rate_limit_trial_user():
    """Trial users limited to 1 request per 30 seconds on /generate."""
    app = create_app()
    async with AsyncClient(app=app, base_url="http://test") as client:
        # First request succeeds
        r = await client.post("/api/v1/generate", json={...})
        assert r.status_code == 200
        # Second request within window gets 429
        r2 = await client.post("/api/v1/generate", json={...})
        assert r2.status_code == 429
```

**Step 2:** `pytest tests/test_rate_limit.py -v` → expect FAIL

**Step 3:** Implement `backend/middleware/rate_limit.py` with:
- Redis sliding window algorithm (ZSET with timestamps)
- Trial users: 1 req/30s on generation, 5 req/hr on auth
- Paid users: 60 req/min on generation
- Returns 429 with `Retry-After` header when exceeded
- Skip for `localhost` in development (if `settings.environment == "development"`)

**Step 4:** `pytest tests/test_rate_limit.py -v` → expect PASS

**Step 5:** Wire into `backend/main.py`:
```python
from backend.middleware.rate_limit import rate_limit_middleware
app.add_middleware(rate_limit_middleware)
```

**Step 6:** Commit

## Risks & Tradeoffs

- **Redis not available in dev:** Rate limiting middleware should gracefully degrade (skip or use in-memory fallback) when Redis is unreachable
- **Sentry adds latency:** Only initialize in production; dev mode is a no-op stub
- **Admin endpoints expose user data:** Ensure proper auth + role check before any data access
- **Migration scripts:** No alembic configured; use ad-hoc scripts like `backend/migrate_indexes.py` and `backend/migrate_sprint8.py`
